## Версии лабораторных

Для каждой лабораторной используется свой префикс тега: `lab1-v1.0.0`, `lab2-v1.0.0`, `lab3-v1.0.0`, `lab4-v1.0.0`. Тег ставится на коммит в ветке соответствующей лабораторной. Пайплайн этой лабораторной проверяет код и публикует готовые файлы в Releases.

Сейчас реализован пайплайн ЛР1 для тегов `lab1-v*`. Пайплайны остальных лабораторных добавляются вместе с их исходниками с соответствующими фильтрами тегов.
