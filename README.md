Лабораторные работы по дисциплине «Проектирование программного обеспечения интеллектуальных систем».

- [Лабораторная 1 — англо-русский словарь и машина Тьюринга](lab1/README.md)
- [Лабораторная 2 — пиццерия](lab2/README.md)

Описание структуры проекта, требования к окружению и команды сборки, запуска, тестирования и генерации документации приведены в README соответствующей лабораторной работы.

## Версии лабораторных

Для каждой лабораторной используется свой префикс тега: `lab1-v1.0.0`, `lab2-v1.0.0`, `lab3-v1.0.0`, `lab4-v1.0.0`. Тег ставится на коммит в ветке соответствующей лабораторной. Пайплайн этой лабораторной проверяет код и публикует готовые файлы в Releases.

Реализованы пайплайны ЛР1 для тегов `lab1-v*` и ЛР2 для тегов `lab2-v*`.
